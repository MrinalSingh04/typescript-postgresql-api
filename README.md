# TypeScript PostgreSQL API

A simple backend setup using **TypeScript, Node.js, Express, and PostgreSQL**.

## Tech Stack

- TypeScript
- Node.js
- Express.js
- PostgreSQL
- `pg`
- dotenv

## Current Progress

- Express server setup
- TypeScript configuration
- PostgreSQL connection
- Environment variable configuration

## Run Locally

```bash
npm install
npm run dev
```

Create a `.env` file with your PostgreSQL connection:

```env
DATABASE_URL=postgresql://username:password@localhost:5432/database_name
PORT=5000
```

Server:

```text
http://localhost:5000
```
